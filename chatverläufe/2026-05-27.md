### 5. Neue Skills erstellt

#### `skills/component-builder/SKILL.md`
Skill für die Implementierung von React-Native-Komponenten (Atoms / Molecules / Organisms).

**Kernregeln:**
- Layer-Hierarchie: Atom → Molecule → Organism → Screen
- Tokens immer aus `../tokens` importieren (keine Magic Numbers)
- `StyleSheet.create({})` konsequent nutzen
- Props-Interface mit `ComponentNameProps`-Suffix exportieren
- Nach Implementierung Export in `design-system/index.ts` eintragen
- Übergabe an `storybook-writer` Skill nach Fertigstellung

#### `skills/storybook-writer/SKILL.md`
Skill für das Erstellen von Storybook-Stories (CSF 3-Format).

**Kernregeln:**
- Titelschema: `Design System/<Layer>/<Name>`
- Imports immer aus `'../../src'` (nie aus Deep-Paths)
- CSF 3: `export default meta; export const StoryName = { args: {} }`
- Atoms: Alle States in einem `AllStates`-Story oder je Variant
- Molecules: Je Inhaltsvariation ein Story
- Organisms: Je interaktivem Zustand ein Story
- Decorator-Patterns für Mobile-Framing (`View`, `width: 360`)
